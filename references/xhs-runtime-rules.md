# XHS 运行规则（DSH）

## 0.1 低 token 与快照约束

- 优先使用 `ego_js` 定向提取字段，减少无意义 dump 与重复抓取。
- 只在关键节点使用 `ego_snapshot`：登录确认、到发布页、填写完成、发布前停顿。
- 截图按需截取视口或元素；只有用户要求整页归档时才扩大范围。
- 重复操作优先复用同一任务空间与 tab；页面变化后重新 snapshot，不复用失效 ref。
- 每个动作最多重试 1 次；第二次失败改稳健路径并汇报。
- 记录账号名、页面状态、按钮可见、字数等关键证据，返回可执行信号。

## 0.2 浏览器稳定规则（最高优先）

- 默认仅使用 `ego_space_open({ name: "default" })` 的 DSH 默认任务空间。
- 每次动作前确认目标 tab；导航用 `ego_navigate`，页面定位用 `ego_snapshot`，点击和输入用对应 `ego_*` 工具。
- 浏览器不可用时先 `ego_status`，再按需 `ego_doctor`；不要切换到 OpenClaw profile 或其他浏览器会话。
- 页面要求登录时，请用户在 DSH 浏览器中手动完成，使用 `ego_wait_for_human` 等待，再执行 `ego_auth_flush`；不要代填密码或验证码。
- 连续 2 次点击/导航失败后改稳健路径（如重新 snapshot 定位或请用户手动完成），不做盲重试。

## 3.5 搜索并浏览（核心约束）

1. 仅从搜索结果页点击进入帖子，禁止直接用 `ego_navigate` 打开 `/explore/<id>`。
2. 默认跳过本账号作者内容，避免自刷。
3. 进入后先校验：不是 404、可见评论/互动信息、可识别标题或作者。
4. 优先点卡片本体，避免点头像/作者名导致跳错。
5. 若评论控件为 `contenteditable` 或 `p.content-input`，先触发输入事件再发送。
6. 两次点击失败或 404 后返回搜索页换下一条，不对同链接直跳重试。

## 6.0 回放与降级

- 搜索结构变化时先 `ego_snapshot` 更新 selector 再继续，不盲跑旧路径。
- 关键页（创作页、探索页、用户页）尽量复用已打开 tab，可用 `ego_tabs` 查看和切换，不重复打开。
- 先告诉用户“已达异常节点”，避免无意义继续操作导致误发。
- 发布页关键动作（切 tab、上传、点击发布）失败时：
  1. 先 snapshot 刷新 ref；
  2. 同动作最多再试 1 次；
  3. 仍失败则切同义入口，或请用户手动完成最后一步。
- 轮播详情页抓图时，禁止取第一个 `.img-container`；必须优先抓取 `.swiper-slide-active:not(.swiper-slide-duplicate) .img-container img`。
- 抓图后人工核对 URL 末段 key 是否与用户指定封面一致；不一致则重新抓取 active 图。
- 图生图产物需要做相似度体感检查：若用户反馈元素过于雷同，切换到 style-only 提示词并重生。
- 上传文件使用 `ego_upload` 和宿主机绝对路径，无需复制到 OpenClaw 临时目录。

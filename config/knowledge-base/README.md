## 当前账号

- 账号名：阿快的AI笔记
- 定位：AI 工具实操笔记，面向想用 AI 提效但没时间研究的普通打工人/开发者
- 人设：见 `config/persona.md`
- 内容支柱（3 个）：
  1. **AI 工具实操**：具体工具/模型的使用步骤、参数、坑（如 Claude/DeepSeek/即梦等）
  2. **提效场景**：用 AI 解决一个具体问题（写文案/读论文/做图/写代码），给前后对比
  3. **避坑与评测**：实测对比、失败记录、不推荐清单（说人话版）

## 目录结构

```

├── README.md          # 本文件：总览 + 当前重点 + 固定索引 + 待整理

└── reviews/           # 结果复盘、失败原因、回退策略、下次修正
```

# patterns/

爆款结构、封面层级、互动机制、可复用 pattern。

- 记录类型：`type: pattern`
- 命名：`YYYY-MM-DD-<pattern-brief>.md`
- 示例：`2026-11-06-three-step-tutorial-hook.md`

分类型字段：
- `title_template`：标题模板
- `cover_template`：封面模板
- `body_template`：正文结构
- `cta_template`：CTA 模板
- `fit_conditions`：适用条件

已验证失效的 pattern 标记为 `status: deprecated`，不要直接删除。
